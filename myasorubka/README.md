
- Локация 3 открывается сразу после эпилога клуба, отдельной кнопки в меню нет.

- Выбор «я останусь рядом»: Мелоди отвечает, что хочет к воскресителю, и уходит его искать. Дальше открывается следующая часть (пока карточка «Что-то другое…»).

### Глава 2 · Локация 3 · продолжение «Ночной город»
- После выбора «я останусь рядом» Мелоди уходит искать воскресителя. Вы идёте по её следам по ночному городу (три следа: мусорный бак, телефонная будка, мост), на мосту появляется воскреситель с выбором ответа и растворяется в тумане.
